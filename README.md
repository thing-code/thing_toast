A package for showing fancy gradient toast in Flutter applications.

## Features

Show 4 Type of Toast : Success, Info, Warning and Error.

## Getting started

Add to your dependencies:

```yaml
dependencies:
  thing_toast: ^1.1.4
```

Then import:

```dart
import 'package:thing_toast/thing_toast.dart';
```

## Usage

To Show Success Toast:

```dart
ThingToast.success(
  context,
  message: 'This is Toast',
);
```
To Show Info Toast:

```dart
ThingToast.info(
  context,
  message: 'This is Toast',
);
```
To Show Warning Toast:

```dart
ThingToast.warning(
  context,
  message: 'This is Toast',
);
```
To Show Error Toast:

```dart
ThingToast.error(
  context,
  message: 'This is Toast',
);
```
